# InternNova Data Analytics Capstone Project

## 📊 Project Overview
This repository contains my end-to-end Data Analytics Capstone Project for InternNova. It demonstrates a complete analytical workflow—covering Git version control, data cleaning, Exploratory Data Analysis (EDA), statistical visualization in Python, interactive Power BI dashboarding, and business strategy formulation.

## 🛠️ Tech Stack & Tools
* **Programming Language:** Python 3
* **Data Manipulation & Analysis:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Business Intelligence:** Power BI Desktop
* **Version Control:** Git & GitHub
